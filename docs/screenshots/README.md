# Screenshots

Lege hier Screenshots der laufenden App ab, damit sie im Haupt-[README](../../README.md) angezeigt werden. Erwartete Dateinamen:

- `dashboard.png` — die Startseite (`/`) nach einem Scan, mit Dateiliste und Sortiervorschlägen
- `scan.png` — die Scan-Seite (`/scan`), auf der ein Ordner eingetragen und der Scan gestartet wird

So machst du sie:

1. `FileArchiver.exe` doppelklicken (oder `python -m archiver serve`) — der Browser öffnet sich automatisch.
2. Auf beiden Seiten jeweils einen Screenshot machen (z. B. `Win`+`Umschalt`+`S` unter Windows).
3. Als `dashboard.png` bzw. `scan.png` in diesem Ordner speichern.
4. Committen und pushen — die Bilder erscheinen dann automatisch im README.

Empfohlene Breite: ca. 1200–1600 px, PNG. Kein Muss — die App funktioniert
auch ohne diese Bilder, sie machen das README nur einladender.
